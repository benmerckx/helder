`DejaVuSans-viewer.ttf`: DejaVu Sans 2.37 (Bitstream Vera's license, with
the DejaVu changes in the public domain: https://dejavu-fonts.github.io/License.html),
subset to Latin-1, Latin Extended-A, the punctuation and arrows the viewer
shows, without hinting (pyftsubset). The viewer's fallback when the system
has no font it finds (a bare Wine prefix, a minimal container).
